Política de Privacidade

Última atualização: 25 de novembro de 2026.

O Dashboard Agências é um aplicativo de uso interno que roda no computador do próprio usuário. Esta política explica quais dados ele acessa e como são tratados.

Dados acessados

Com a autorização do usuário, o aplicativo lê, pela Google Ads API (escopo https://www.googleapis.com/auth/adwords) e pela Meta Marketing API (permissão ads_read), informações das contas de anúncios às quais o usuário já tem acesso: nomes de contas e campanhas, investimento, impressões, cliques, conversões e orçamentos. Também lê o endereço de e-mail da conta Google autorizada, apenas para identificar a conexão na tela.

Uso dos dados

Os dados são usados exclusivamente para exibir relatórios, ritmo de verba e alertas ao próprio usuário. O aplicativo é somente leitura: não cria, altera nem exclui campanhas, anúncios ou configurações das plataformas.

Armazenamento e compartilhamento

Os dados e as autorizações ficam gravados apenas no computador do usuário; as credenciais são protegidas pelo Windows (DPAPI). Não existe servidor do aplicativo na internet. Os dados não são vendidos, compartilhados nem transferidos a terceiros, e não são usados para publicidade.

Uso de dados do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

Revogação e exclusão

O usuário pode remover a conexão a qualquer momento no próprio aplicativo (Conexões › Remover) e revogar o acesso em myaccount.google.com/permissions ou nas configurações de Integrações Comerciais do Facebook. Apagar a pasta de dados do aplicativo exclui todas as informações guardadas.
